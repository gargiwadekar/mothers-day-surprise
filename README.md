# Mother’s Day Surprise — React + Tailwind + Framer Motion

This is a single-page premium-looking Mother’s Day surprise site scaffolded with Vite, Tailwind CSS and Framer Motion.

Quick start:

1. Install dependencies

```bash
npm install
```

2. Start dev server

```bash
npm run dev
```

Notes:
- Add a background music file at `src/assets/sample.mp3` (or edit `MusicPlayer.jsx` to use an online source).
- Replace `src/assets/mom.svg` and `src/assets/mem*.svg` with real photos.
- This scaffold focuses on aesthetics and animations; tweak styles in `src/index.css` and components.

Important assets to add for full experience:

- `src/assets/sample.mp3` — soft emotional background music (loop)
- `src/assets/pop.mp3` — short balloon pop sound
- `src/assets/finale.mp3` — optional finale music for big surprise
- Replace `src/assets/mem*.svg` and `src/assets/mom.svg` with high-quality photos (JPEG/PNG)

Run notes:

If you open the dev server and see missing audio, replace the placeholder files above with real mp3 files. The cinematic experience is designed to be completed by adding these assets.

To preview the cinematic flow, run dev and click through the scenes using the on-screen buttons or arrow controls.
